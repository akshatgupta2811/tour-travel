# Bus Booking Application

A simple, interactive frontend web application for a Travel Agency's bus booking system. Built using standard HTML, CSS, and JavaScript.

## Features

* **Booking Form:** Collects essential travel details including destination, travel date, and number of seats.
* **Instant Confirmation:** Uses JavaScript to handle form submission dynamically, displaying a customized booking confirmation message instantly without reloading the page.
* **Clean UI:** A neatly styled, user-friendly interface using CSS, complete with hover effects and accessible input fields.

## Files Included

* `index.html`: The main structure and layout of the travel agency booking page.
* `styles.css`: The styling rules that provide a clean, modern look with a centered form and styled buttons.
* `script.js`: The client-side logic that captures form data, prevents default form submission, and renders the confirmation message.

## How to Run

1. Ensure all three files (`index.html`, `styles.css`, `script.js`) are saved in the same folder or directory.
2. Open the `index.html` file in any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
3. Fill in the **Destination**, select a **Travel Date**, and enter the **Number of Seats**.
4. Click the **Book Now** button to see your instant booking confirmation appear at the bottom of the form!
